# Studio-FitCore
O Studio FitCore é um site criado para organizar os treinos e melhorar a comunicação entre alunos e personal trainers, substituindo as antigas fichas impressas e mensagens no WhatsApp que ficaram desorganizadas com o aumento de alunos. O site facilita o acesso às informações, o acompanhamento da evolução e a rotina dos profissionais, sendo feito com HTML5 para estrutura e CSS3 para o visual. A arquitetura é simples, com index.html para a página principal e style.css para o estilo, e para executar basta baixar o projeto e abrir o index.html no navegador. O objetivo final é melhorar a organização e a experiência dos alunos da academia.
